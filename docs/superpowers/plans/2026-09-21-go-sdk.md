# Native Go SDK implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native Go recorder that passes the same wire contract as Node and Python and works in a separate Go application without publication.

**Architecture:** A bounded synchronous capture core builds immutable envelope bytes. A typed facade and generic wrapper functions enqueue those bytes into a bounded, cancellation-aware HTTP sender. A public-API fixture driver captures actual HTTP bodies for unchanged replay through the real API.

**Tech Stack:** Go 1.26 standard library, testing/httptest, race detector and vet; existing TypeScript/Vitest/PostgreSQL integration infrastructure.

**Spec:** `docs/superpowers/specs/2026-09-20-go-sdk-design.md`.

## Global Constraints

- Implement only after Python passes its local conformance, packaging and task-review gates. Python's first real API conformance run is now green; its remaining packaging/review work may finish while this plan is prepared.
- Package `wayscribe`, module `gitlab.com/jojithedev/wayscribe/packages/sdk-go`, `go 1.26`, fixed SDK name `wayscribe-go` and development version `0.1.0-dev`, unpublished. Runtime and tests require no third-party Go module.
- SDK_SPEC SDK-1 through SDK-67, INGESTION_CONTRACT and PROPAGATION_SPEC are authoritative. Protocol version remains `0.1`; no API/schema changes.
- No fixture expectations may be weakened. All universal SDK fixtures execute; the two Node-only cases are explicit named skips. Shared propagation and HMAC vectors remain literal.
- Record calls perform capture immediately but never wait on network I/O. Host callback values, errors, cancellation and panic behavior survive instrumentation.
- No ambient SDK configuration, proxy credentials, hostname/process metadata or OpenTelemetry requirement. Full capture stays an explicit opt-in.
- Input maps/slices must remain stable during synchronous capture; after recording, caller mutation cannot alter sent bytes. Race checks cover SDK state and independent stable caller inputs.
- No GitLab operations, push, publication, release tags, deployment, account changes or outreach. Use the sdk-expansion worktree and owned local test resources only.
- Keep native SDK source/tests outside server images. Do not prune unrelated containers, volumes, images or caches.

## API decisions and task seams

Public types and function signatures are fixed here so each task can be reviewed independently. Task1 supplies their actual internal counterpart signatures in its report; Task2 supplies the public facade/interface map for Task3.

```go
type Entity struct { Type, ID string }
type Context struct {
    JourneyID string `json:"journeyId"`
    Entity *Entity `json:"entity,omitempty"`
}
type Operation string // constants for all eleven protocol operations
type PropagationLevel string // JourneyOnly, JourneyAndType, Full
type CaptureMode string // protocol capture modes; zero selects redacted-payload

// A zero Value is absent. Payload(nil) explicitly records JSON null.
// Payload only marks presence; capture happens synchronously in Record/wrappers.
type Value struct { value any; present bool }
func Payload(v any) Value
func (v Value) Get() (any, bool) // original supplied value and presence, not a capture operation

type ErrorInfo struct { Type, Message, Code, Stack string }
type Event struct {
    Operation Operation
    Name string
    Input, Output Value
    Error *ErrorInfo
    Metadata map[string]any
    Aliases map[string]string
    DisplayableAliases []string
    Timestamp time.Time // zero means time of Record
    DurationMS *int64 // nil absent; pointer to zero is a measured zero
    Attempt int // zero means absent/default first attempt
    ParentEventID, TraceID, SpanID, MessageID, CorrelationID string
}
type JourneyOptions struct { JourneyID, Label string }
type LabelOptions struct { Label string }
type IdentifyOptions struct { DisplayableAliases []string }
type FailureReason struct { Message, Code string }
type Options[I, T any] struct {
    Attempt int
    Metadata map[string]any
    Aliases map[string]string
    DisplayableAliases []string
    CaptureInput func(I, Context) any
    CaptureOutput func(T, Context) any
    MetadataFrom func(T, Context) map[string]any
    IsFailure func(T) *FailureReason // nil success; non-nil records a failed result
}
```

Add JSON tags to Entity fields and all serialized public carrier structures. Event is a caller input, not an alternate wire schema; serialize only through the core builder. Keep optional fields absent unless supplied. A raw Event's aliases and metadata are typed maps; unsupported runtime values remain possible inside payload/metadata and must be guarded.

`Config` exposes Endpoint, APIKey, Service, Environment, CaptureMode, Redact and KnownSafeNames, JourneyIDSecret, Propagation, Deployment (`map[string]string`), OnDiagnostic (`func(Diagnostic)`) and LogDiagnostics. CaptureMode constants are MetadataOnly (`metadata-only`), RedactedPayload (`redacted-payload`) and FullPayload (`full-payload`). Delivery fields are BatchSize, MaxBufferedEvents, MaxEventBytes, MaxConcurrentSends, MaxAttempts, BreakerThreshold, EventRetryMaxSends (ints), and FlushInterval, RequestTimeout, BackoffBase, BackoffMax, BreakerReset, EventRetryBudget (`time.Duration`). Zero optional numbers/durations mean omitted and use defaults; negatives are rejected, reported by setting name and replaced. Positive settings follow the protocol/default clamps. Required strings must be nonblank and valid. Optional lists/maps are detached and bounded. No ignored knob.

Defaults: batch50, flush1s, timeout1500ms, buffer1000, event262144bytes, concurrent4 clamped1–16, attempts3, backoff100ms/2s, breaker5/30s, refusal30s/10 logical sends. Refusal sends and HTTP attempts are distinct. Diagnostics are detached safe structs (Kind, Code, Field, Name, Path, Shape and other explicitly safe numeric/enum fields as needed); counters include all SDK_SPEC totals and dropped-by-cause. Do not expose raw caller values, errors, keys or endpoints in printed diagnostics.

### Task 1: Typed protocol, bounded capture and propagation core

**Files:**
- Create `packages/sdk-go/{go.mod,LICENSE,NOTICE,README.md,doc.go,version.go,types.go,config.go,diagnostics.go,capture.go,errors.go,event.go,propagation.go,timing.go}` and covering `*_test.go` files.
- Add only Go-owned generated artifact patterns to `.gitignore` if necessary.

**Interfaces:**
- Implement the public pure types above, `Payload(any) Value`, fixed Version and SDK identity, and detached resolved configuration/diagnostics used by Task2. No goroutines/network in the pure core.
- Internal envelope builder takes resolved config, diagnostics, a journey ID, a detached Entity, a label and Event, returning immutable `[]byte` or a refused result. It owns capture diagnostics/counters, while Task2 owns recorded/delivery/drop accounting. Record actual signatures in the report.
- `InjectHTTPHeaders(Context, map[string]any, PropagationLevel) map[string]any`; `ExtractHTTPContext(any) *Context` recognizes map[string]any, map[string]string and http.Header without calling arbitrary application methods. Injection copies and preserves unrelated fields; the zero privacy level uses the middle default. The raw map supports literal cross-language vectors; README shows copying injected string values to a request's http.Header.
- `InjectSQSAttributes(Context, map[string]any, PropagationLevel) map[string]any`; `ExtractSQSContext(map[string]any) *Context`; `InjectPayload(Context, any, PropagationLevel) map[string]any`; `ExtractPayload(any) (data Value, context *Context)`; `HasJourney(any) bool`. Extracted Value preserves absent envelope data versus explicit nil; callers use Get to inspect presence. A body without an envelope is returned as a present Value, including a nil body. The fixture adapter must omit missing data instead of inventing JSON null.
- Timing API: `QueueMetadata(QueueJob, QueueTimingOptions) map[string]any`, `HTTPMetadata(HTTPResponse, HTTPTimingOptions) map[string]any`. QueueJob has QueueName/ID strings and TimestampMS/ProcessedOnMS/AttemptsMade *int64; QueueTimingOptions has ReadyAgainAtMS/DeliveryCount *int64. HTTPResponse has StatusCode int and Headers http.Header; HTTPTimingOptions has TargetURL string and ObservedAt *time.Time. Nil clocks/counts mean unknown, while a pointer to zero is known zero. Use exact metadata vocabulary/bounds from EVENT_PROTOCOL section9.

### Task 2: Recorder, generic wrappers and cancellation-aware delivery

**Files:**
- Create `packages/sdk-go/{recorder.go,journey.go,wrappers.go,transport.go,context.go}` and covering tests; modify types/core/README only for integration.

**Interfaces:**
- `New(Config) *Recorder` always returns a usable recorder. `Journey(Entity, ...JourneyOptions) *Journey`, `Resume(Context, Entity) *Journey`, `ForEntity(Entity, ...LabelOptions) *Journey`, `Across(...*Journey) *Group`, `Counters() Counters`, `RejectedSettings() []string`, `Flush(context.Context) bool`, `Shutdown(context.Context) bool`. Optional variadic option structs accept at most one object; extra objects are safely diagnosed. ForEntity has no explicit-ID override because its purpose is the specified keyed derivation.
- Journey methods: `Context() Context`, `Label(string)`, `Record(Event)`, `Identify(map[string]string, ...IdentifyOptions)`, `Fail(string, error)`, `Complete(string)` (empty completion name uses complete). Group supports Record/Fail/Complete and wrappers; deduplicate journey IDs and accept only members of the owning recorder.
- Define sealed `Target` implemented by *Journey and *Group. Public package-level `Transform[I,T any](context.Context, Target, string, I, func(context.Context)(T,error), ...Options[I,T]) (T,error)` plus Persist/Publish/Consume/Deliver/Validate with the same signature and natural operations. Options omitted means defaults; accept at most one options object and safely diagnose additional ones. Host callback runs once even for a nil target, disabled recorder or empty group.
- `WithJourney(context.Context, *Journey) context.Context`, `JourneyFromContext(context.Context) (*Journey, bool)` use an unexported distinct key type and preserve cancellation/deadline. No context value becomes an event field automatically.
- Lifecycle bool means accepted work reached terminal accounting within the bound, not that all events were stored. A context without a deadline still uses a documented five-second upper bound. Nil context safely uses that same bound. A canceled Flush returns without leaking a waiter; Shutdown closes admission, cancels sender work and finalizes owned events once.
