# Support

Wayscribe is an early-stage, self-hosted open-source project. Support is provided
by the maintainer and community on a best-effort basis. There is no guaranteed
response time, resolution time, or service-level agreement.

## Find help

Start with the [quick start](README.md#try-it),
[troubleshooting guide](docs/TROUBLESHOOTING.md), and [FAQ](docs/FAQ.md).
Search [existing GitLab issues](https://gitlab.com/jojithedev/wayscribe/-/issues)
before opening a new one.

Use the appropriate template:

- [Ask a question](https://gitlab.com/jojithedev/wayscribe/-/issues/new?issuable_template=question)
  for setup, configuration, or usage help.
- [Report a bug](https://gitlab.com/jojithedev/wayscribe/-/issues/new?issuable_template=bug)
  for behavior that does not match the documentation.
- [Request a feature](https://gitlab.com/jojithedev/wayscribe/-/issues/new?issuable_template=feature)
  to describe a problem and the behavior that would help.

GitLab is the public support channel. The GitHub repository is a read-only
mirror; please use GitLab for questions, issues, and merge requests.

## What to include

Describe what you are trying to do, what you expected, what happened, and what
you have already tried. Include the Wayscribe version or commit, relevant SDK
and runtime versions, deployment method, and a small reproduction when possible.
The [supported versions](README.md#supported-versions) table describes the
environments the project tests.

Public issues are visible to everyone. Use synthetic examples and sanitized
logs. Do not include API keys, tokens, encryption keys, credentials, real
customer payloads, or other private information.

## What to expect

The maintainer reviews issues as time permits and may ask for more information
or a reproduction. A report or feature request does not guarantee a fix, an
implementation, or a delivery date. Maintainer capacity, impact, reproducibility,
and the project's [scope](docs/PRODUCT_PRINCIPLES.md) guide prioritization.

For changes you would like to contribute, see [Contributing](CONTRIBUTING.md).
Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

## Private reports

- **Security vulnerabilities:** use [the security policy](SECURITY.md) and
  email [security@wayscribe.dev](mailto:security@wayscribe.dev). The security
  policy has its own acknowledgement expectation.
- **Conduct concerns:** email [conduct@wayscribe.dev](mailto:conduct@wayscribe.dev)
  and read [who receives reports](CODE_OF_CONDUCT.md#enforcement).

Please use these private routes instead of a public support issue for such reports.
